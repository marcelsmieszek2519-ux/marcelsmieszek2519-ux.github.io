Privacy Policy

Publikator · last updated 24 October 2026

Publikator is a personal tool operated by Marcel Śmieszek ("I", "the author") that uploads the author's own videos to the author's own accounts. This policy explains what data it handles.

Who uses it and what data it handles

The application has a single user: the author. It connects only to accounts owned by the author. It does not collect personal data about any other person, and it has no registration, advertising or analytics.

When the author signs in with Google (and, where available, TikTok or Instagram), the application receives an access token for that account. It uses it only to upload the author's videos and thumbnails and to set their title, description and settings.

Where data is stored

Access tokens, video files and queue settings are stored only on the author's own computer. They are not uploaded to any server operated by me and are not shared with, sold to, or transferred to any third party. The application's status page is served from the author's own computer and is not available on the public internet.

Google user data

Publikator uses the YouTube API Services. Its use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. By using the YouTube API Services, the author is bound by the YouTube Terms of Service; Google's handling of data is described in the Google Privacy Policy. The only Google scope requested is youtube.upload.

Other platforms

If the author connects TikTok or Instagram, the same rules apply: access is used only to publish the author's own videos to the author's own account, and tokens stay on the author's computer. Each platform's own privacy policy governs data held by that platform.

Retention and deletion

Tokens and files are kept until the author deletes them. Access can be revoked at any time at myaccount.google.com/permissions (Google), and in the security settings of the other platforms. Revoking access makes the stored token useless.

Children

Publikator is not directed at children and collects no data from them.

Changes

If this policy changes, the date above will be updated.
