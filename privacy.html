Privacy Policy

Publikator · last updated 28 October 2026

Publikator is a personal tool operated by Marcel Śmieszek ("I", "the author") that uploads the author's own videos to the author's own accounts. This policy explains what data it handles.

Who uses it and what data it handles

The application has a single user: the author. It connects only to accounts owned by the author. It does not collect personal data about any other person, and it has no registration, advertising or analytics.

When the author signs in with Google or TikTok, the application receives an access token for that account. It uses it only to upload the author's own videos (and, for YouTube, thumbnails) and to set their title, description and settings.

Google user data

Publikator uses the YouTube API Services. By using Publikator, the user agrees to be bound by the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy (www.google.com/policies/privacy).

What Publikator accesses. The only Google permission (OAuth scope) requested is https://www.googleapis.com/auth/youtube.upload. With it, Publikator receives an OAuth access token and refresh token for the author's account and, after each upload, YouTube's response: the new video's ID and its upload and privacy status. Publikator does not request or receive the author's name, e-mail address, contacts, existing videos, playlists, comments, subscribers, analytics or any other Google data.

How it is used. The token is used only to upload the author's own video file with the title, description, tags, category, language, privacy setting and altered-or-synthetic-content disclosure that the author entered (YouTube Data API videos.insert), and to set the custom thumbnail of that same video (thumbnails.set). The returned video ID is used only to show the author a link to the video in YouTube Studio and to keep a history of the author's uploads. Google user data is not used for advertising, is not sold, and is not used to develop, improve or train AI or machine-learning models. No person other than the author reads it.

Limited Use. Publikator's use and transfer to any other app of information received from Google APIs will adhere to Google API Services User Data Policy, including the Limited Use requirements.

Where data is stored and how it is protected

Access and refresh tokens, video files and queue settings are stored only on the author's own computer, in the application's folder, protected by the author's Windows account. Tokens are never sent anywhere except to Google (or TikTok) over encrypted HTTPS connections when the application calls the official APIs.

So that the author can check the queue on the author's own phone, the application copies a status summary (video titles, schedule, upload status, small thumbnail previews and the links to the uploaded videos, including their YouTube video IDs) to a private Google Firebase (Cloud Firestore) database in the author's own Google Cloud project. That database can be read only after signing in with the author's own password. Tokens, passwords and video files are never copied there.

Data is not shared with, sold to, or transferred to any third party. The application's status page on the computer is served from the author's own computer and is not available on the public internet.

Cookies

The desktop application stores no cookies on anyone's device. This website does not use cookies, analytics or advertising.

TikTok user data

Publikator uses TikTok Login Kit and the TikTok Content Posting API in Upload mode. The author signs in with the author's own TikTok account and approves two permissions:

  • user.info.basic: used only to read the display name of the connected account, so that the application can show which account is connected.
  • video.upload: used only to send the author's own finished videos to the author's own TikTok inbox as drafts.

The author then reviews and publishes each draft manually in the TikTok app. Publikator does not publish anything on TikTok by itself, does not read the author's videos, followers, messages or analytics, and does not collect any data about other TikTok users. The TikTok access token and refresh token are stored only on the author's own computer, are not shared with anyone and are not used for advertising, analytics or any other purpose. TikTok's handling of data is governed by TikTok's own Privacy Policy and Terms of Service.

Other platforms

Instagram is not connected at present. If it is added in the future, the same rules apply: access is used only to publish the author's own videos to the author's own account, and tokens stay on the author's computer.

Retention and deletion

Tokens and files are kept until the author deletes them. Access can be revoked at any time on the Google security settings page at myaccount.google.com/permissions (Google) and in the security and permissions settings of the TikTok app (TikTok). Revoking access makes the stored token useless immediately. After access to Google is revoked, the author deletes the stored Google token file and the upload history derived from Google data from the computer and from the status database within 7 days. Anyone can ask for deletion of data or ask questions about this policy by e-mail to the contact address below; requests are answered within 30 days.

Children

Publikator is not directed at children and collects no data from them.

Changes

If this policy changes, the date above will be updated.
